# ResumeIQ Project Specification

## Objective
Create an explainable NLP application that compares a resume with a target job description and provides skill, keyword, semantic, quality, and evidence analysis.

## Required inputs
- Resume PDF
- Job description text

## Required features
- PDF extraction
- preprocessing
- section extraction
- NER
- skill extraction
- TF-IDF
- cosine similarity
- semantic similarity
- explainable score
- skill gap
- evidence map
- keyword placement
- quality audit
- bullet analysis
- interview question generation
- version comparison
- downloadable report

## Production
Production application must be deployable on Vercel using Next.js/TypeScript.

## Academic reference layer
Provide Python implementation/examples using NLTK, spaCy, scikit-learn and Word2Vec where practical.

## Important
The Match Score is an educational NLP similarity indicator and is not a hiring prediction.
