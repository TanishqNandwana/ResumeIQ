# Vercel Production Checklist

## Before deployment

- [ ] `npm install` works
- [ ] `npm run build` passes
- [ ] tests pass
- [ ] no secrets in repository
- [ ] `.env` ignored
- [ ] private resumes excluded
- [ ] sample data is synthetic/public
- [ ] upload validation works
- [ ] API routes work

## Deployment

- [ ] Vercel login complete
- [ ] correct GitHub repository selected
- [ ] Next.js detected
- [ ] build succeeds
- [ ] production deployment succeeds

## After deployment

- [ ] homepage opens
- [ ] analysis page works
- [ ] PDF upload works
- [ ] job description processing works
- [ ] score is calculated dynamically
- [ ] skill gap works
- [ ] evidence map works
- [ ] quality audit works
- [ ] interview questions work
- [ ] version comparison works
- [ ] report works
- [ ] mobile layout works
- [ ] no console errors
- [ ] no server errors

Only then declare deployment complete.
